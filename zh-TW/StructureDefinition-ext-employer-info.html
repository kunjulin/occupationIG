擴充: 雇主事業單位資訊擴充

正式網址: https://twcore.mohw.gov.tw/ig/twha/StructureDefinition/ext-employer-info 版本: 0.8.5
Active 截至 2026-08-21 機器可讀名稱: ExtEmployerInfo

【技術規格】關聯受檢勞工所屬之事業單位組織資料，或臨場服務事件/活動所針對之事業單位。

Context of Use

    This extension may be used on the following element(s)

    • Element ID: Patient
    • Element ID: Encounter
    • Element ID: Procedure
    • Element ID: Task

Usage info

Usages:

  • Use this Extension: 臨場健康服務事件 Profile, 受檢者 Profile, 臨場服務執行活動項目 Profile and 臨場健康服務建議與改善任務 Profile
  • Examples for this Extension: Bundle/UC-001, Bundle/UC-002, Bundle/UC-003, Bundle/UC-004... Show 7 more, Bundle/UC-005, Bundle/UC-006, Bundle/UC-007, Encounter/example-encounter-service, Patient/example-worker, Procedure/example-procedure-activity and Task/example-service-task

You can also check for usages in the FHIR IG Statistics
