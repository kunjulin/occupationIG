This guide is not an authorized publication; it is the continuous build for version 0.1.0 built by the FHIR (HL7® FHIR® Standard) CI Build. This version is based on the current content of https://github.com/kunjulin/occupationIG and changes regularly. See the Directory of published versions

ValueSet: 健康檢查進階與領域擴充項目值集

: https://twcore.mohw.gov.tw/ig/twha/ValueSet/VS-ExtendedDataset : 0.1.0
Active : VS_ExtendedDataset
