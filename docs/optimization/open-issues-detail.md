## T-6 六個值集被排除於驗證之外 <a id="t-6"></a>

- **【A】有實質理由，應長期保留（1 個）**：`VS-UnfitDiseases`。其定義為
  `include codes from system ICD10CM`，即**意向式引用整個 ICD-10-CM 代碼系統**；
  此類 include 須由術語伺服器展開整個外部代碼系統，展開量極大且相依於 tx 端是否服務
  ICD-10-CM。**這是 `no-validate` 的正當用途。**
- **【B】已具備移除條件，惟須先量測（5 個）**：其餘五者均為逐碼列舉之 LOINC／SNOMED
  清單，且已通過 JOB-01 顯示名稽核（Wrong Display Name = 0）與 JOB-19／20 之
  UCUM／Scale 稽核。

**待決（續辦）**　【B】五項之實際移除。**本版不逕行移除**——移除後可能一次浮出大量訊息，
而本專案既定原則為**不憑猜測、不預先猜測 QA 數字**。CI 已提供實驗開關
（`workflow_dispatch` 之 `drop-no-validate`），設為 `true` 時建置前移除【B】五項並照常
產出 `qa.txt`，即可取得實測值作為決策依據。取得實測值後另以一次版本變更移除。
