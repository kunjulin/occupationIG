## 使用原則

建立或修訂涵蓋度對照表、法定必驗值集時，**須逐項核對本目錄之 PDF 原文**，
不得僅憑既有 markdown 表格轉抄——既有表格本身即為待驗證之產物。
相關工作見 [JOB-07](../optimization/JOB-07-scenario-required-valuesets.md)。

## 著作權

法律、命令依《著作權法》第 9 條不得為著作權之標的。
本目錄之 PDF 為主管機關公告之法規附表，收錄於此僅為實作對照之便。
